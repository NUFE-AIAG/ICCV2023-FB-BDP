# ICCV2023-FB-BDP
Peanut Leaf Dataset - PeanCultivar120
## Download  
Dataset can be download in [PeanCultivar120.rar](https://drive.google.com/file/d/1Dz3VrPbl-xbZ6nbeXfultvUVFSidNN1A/view?usp=drive_link)  

NOTE: The dataset is publicly available for non-commercial use. Please refer to "Xin Chen, Bin Wang, and Yongsheng Gao. "Fan-beam binarization difference projection (FB-BDP): A novel local object descriptor for fine-grained leaf image retrieval." Proceedings of the IEEE/CVF International Conference on Computer Vision. 2023." if you use this dataset in your publication.

## Details  
We collect 600 leaves of 120 peanut cultivars with 5 sample per cultivar to build a peanut leaf image dataset, named PeanCultivar120. All the peanut leaves are randomly collected from the upper part of different plants.
